# AH-64D Symbology Guide

A labeled visual guide to the four IHADSS symbology modes in the DCS AH-64D: Cruise, Transition, Hover and Bob-Up, plus the cueing elements and the High Action Display. Every HUD element is numbered on an in-game screenshot with a description of what it does. Click a marker or a legend line to pin it.

Open `index.html` in a browser. It is a single self-contained file.
